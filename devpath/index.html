Who this is for

Three kinds of people start here. All three can finish.

The path assumes nothing except a laptop, an internet connection and the willingness to be bad at something for a few weeks.

🌱 You've never written code

You'll start by learning what actually happens when a page loads, then write real HTML the same week. Nothing assumes prior knowledge — every term is explained the first time it appears.

🧩 You know some HTML & CSS

You can make a page but the pieces feel unrelated. Stages 5 to 8 are where JavaScript, React and a real API turn scattered knowledge into a system you can reason about.

🧗 You're self-taught and stuck

Tutorials aren't the problem — order is. The later stages cover the gaps self-teaching usually leaves: SQL, authorisation, tests, CI and what happens after deployment.

The method

Learn a little, build a lot, prove it.

Every stage repeats the same three moves. That repetition is the whole trick — it's how a hobby becomes a skill someone will pay for.

📖 1 · Learn the minimum

Four to six lessons per stage, each a concrete thing to do rather than a video to watch. Read the docs, break things, read the error.

🔨 2 · Build the proof

Every stage ends in a small build with a definition of done. If you can't build it, the lessons weren't finished — that's the feedback loop.

🚀 3 · Put it online

Deployed, linked from a README, explained in a sentence. Work nobody can see doesn't count as a portfolio.

Straight answers

The questions people actually ask.

No hype on this page. If something here is hard, it says so.

Do I need a computer science degree?

No. Interviews test whether you can build and reason, and the path covers the parts of CS that come up in practice: data modelling, complexity, and reading code you didn't write. A degree helps with some visas and some large companies' filters; it is not a prerequisite for the work.

How long does it really take?

The path is 186 focused hours. At ten hours a week that's about 19 weeks of learning, which is why it's laid out over 24 — life happens. At five hours a week, plan for roughly nine months. Anyone promising four weeks is selling something.

Is any of it paid?

No. Every stage points at free documentation and free practice: MDN, web.dev, javascript.info, official React and Node docs, SQLBolt, OWASP. You'll want a free GitHub account, and a free hosting account for the deploy weeks.

Do I have to learn everything before applying for jobs?

You should apply once you can build a CRUD app with auth and explain your choices — which is around stage 10, not stage 12. The last stages make you competitive; waiting for "ready" is how people wait forever.

What if I get stuck?

Getting stuck is the curriculum. The skill being trained is: reproduce it small, read the error, search the exact message, read the docs, then ask a specific question. There's a short protocol for this in the toolkit.

Is my progress saved anywhere?

In your browser's local storage, on this device. Nothing is sent anywhere and there's no account. Use “Export” on the roadmap if you want a copy before clearing your browser data.
